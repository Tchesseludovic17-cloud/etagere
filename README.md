# Étagère

Une plateforme simple pour les outils vidéo.

Deux outils sont prêts :

- **Titres animés** — un bandeau (nom, rôle, style) qui se joue tout de suite.
- **Le goût** — à partir d’un texte, des propositions : quoi couper, quoi garder, où poser le titre. Oui ou non, mémorisé sur l’appareil.

Sous-titres et « Mon style » sont annoncés, pas encore là.

Rien n’est envoyé sur internet. Les choix restent dans le navigateur.
